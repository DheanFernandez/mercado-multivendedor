# Evidencias del Sprint 03

> **Todavía no hay evidencias.** La aplicación no está desplegada.

## Estructura

Se sigue la convención de las evidencias de los sprints anteriores: una carpeta por fecha.

```text
evidencias/
└── <aaaa-mm-dd>/
    ├── README.md       qué se verificó, comando, resultado y veredicto
    ├── entorno.txt     proveedor, región, commit desplegado y versiones
    └── salidas/        salidas de las herramientas (sin secretos ni datos personales)
```

## Campos obligatorios de cada evidencia

| Campo | Contenido |
|---|---|
| Fecha | Día y hora de la prueba |
| Entorno | Proveedor, región y plan |
| Commit | Hash completo del commit desplegado |
| Herramienta | Nombre y versión |
| Comando | Comando exacto, sin secretos |
| Resultado | Valores observados frente al criterio |
| Limitaciones | Qué no cubre la prueba |

Antes de añadir una evidencia, hay que eliminar de las salidas tokens, contraseñas, cadenas de conexión, correos y rutas locales.
